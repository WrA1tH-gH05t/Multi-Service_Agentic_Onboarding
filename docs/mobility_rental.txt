Mobility / Rental Service

Service Overview:
The Mobility Rental service is designed for vehicle rental and mobility service registration. This service requires a valid driving license and has same-day processing when the document is valid and clearly readable.

Requirements:
- One valid Driving License (NO alternatives accepted)
- License must not be expired
- License must be valid in the country of service
- Document format: PDF, JPG, PNG, or TIFF

Process:
1. Customer initiates a mobility rental application
2. System confirms driving license is required
3. Customer uploads the driving license
4. System extracts fields:
   - Front page: name, license no, nationality, date of birth, issue date, expiry date, licensing authority, place of issue
   - Back page: traffic code no, gear type (automatic / manual gear), glasses restriction (glasses logo / no glasses logo)
5. Validation agent checks:
   - Document is valid (not expired)
   - Name entered matches the driving license
   - All mandatory fields (name, license no, nationality, issue date, expiry date, licensing authority, traffic code no, gear type, glasses requirement) are present and readable
   - Transmission / gear eligibility (automatic or manual gear) is verified
   - Correct vision correction restrictions (glasses logo / no glasses logo) are noted
6. Application status determined:
   - Complete: all checks pass
   - Needs human review: confidence issues or borderline expiry
   - Rejected: expired license or invalid document

Processing Time:
Same day (if document is valid and clearly readable)

Field Requirements:
- Name: mandatory (as per driving license)
- License no: mandatory
- Nationality: mandatory
- Date of birth: mandatory
- Issue date: mandatory
- Expiry date: mandatory (must be future date)
- Licensing authority: mandatory
- Traffic code no: mandatory (from back page)
- Automatic gear / manual gear: mandatory (from back page)
- Glasses logo / no glasses logo: mandatory (from back page)

Validation Rules:
- License must not be expired
- Name must match format requirements (2+ characters)
- License number and traffic code number must be present
- Transmission must be specified as Automatic Gear or Manual Gear
- Glasses restriction must be identified (glasses logo present vs absent)

Important Notes:
- Unlike the Basic Registration service, this service does NOT accept a National ID card
- The driving license is the ONLY accepted document for this service
- If the license is expired, the application will be rejected
- Same-day processing is available ONLY if the document quality is sufficient
