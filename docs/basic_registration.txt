Basic Registration Service

Service Overview:
The Basic Registration service is the simplest onboarding option, designed for customers who need standard identity verification for common services. This service accepts a single document for identity verification.

Requirements:
- One National ID card (primary) OR Driving License (accepted alternative)
- Document must be clearly photographed or scanned
- File format: PDF, JPG, PNG, or TIFF
- Maximum file size: 200MB
- Document must be valid (not expired)

Process:
1. Customer initiates a basic registration request
2. System confirms the required document type (national ID or driving license)
3. Customer uploads the document
4. System extracts key fields: name, date of birth, document number, expiry date, issuing country
5. Validation agent checks the extracted data against the golden dataset
6. If extraction confidence is high (>0.7), the application is marked complete
7. If extraction confidence is low or fields are missing, the application is sent to human review

Processing Time:
1-2 business days from complete submission

Data Stored:
- Extracted fields from the document
- Processing status (complete, incomplete, needs human review)
- Timestamp of submission
- Document file stored in secure object store

Important Notes:
- The system will NOT accept other document types (passport, utility bill, etc.) for this service
- If the document is expired, the system will flag it for human review
- The customer must upload a clear, legible document. Blurry or incomplete images will be rejected with specific feedback
